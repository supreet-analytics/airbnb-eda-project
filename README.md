# 🏠 Airbnb Listings – Exploratory Data Analysis

## 📌 Project Overview
This project involves performing Exploratory Data Analysis (EDA) on Airbnb listings data to uncover meaningful patterns and insights. The goal is to identify trends in pricing, availability, and location to better understand the dynamics of Airbnb’s marketplace. The analysis also helps in drawing actionable insights that could aid hosts, guests, or businesses in making data-driven decisions.

---

## 🛠️ Tools & Technologies Used
- **Python**  
- **Pandas, NumPy** – Data manipulation and preprocessing  
- **Matplotlib, Seaborn** – Data visualization  
- **Jupyter Notebook** – Interactive coding environment  

---

## 🔍 Key Steps Performed
- Collected and loaded Airbnb dataset
- Cleaned and transformed raw data (null handling, duplicates, data types, eliminated unnecessay columns)
- Conducted univariate and bivariate analysis
- Performed feature engineering to create new variables from existing data for deeper insights (e.g., price per bed)
- Visualized key features affecting price and availability
- Identified correlations among numerical features
- Highlighted insights using plots like heatmaps, boxplots, histograms, etc.

---

## 📊 Key Insights
- Listings with higher number of reviews often have lower prices
- Neighborhoods significantly influence price variations
- Availability peaks around tourist seasons and drops off otherwise
- Room type and number of minimum nights stay impact booking likelihood
